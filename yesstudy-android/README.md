# Yes Study in Malaysia Android App

This Android app is a thin WebView wrapper for:

https://yesstudyinmalaysia.kashmirinfo.com/

It does not duplicate or modify the website database. Website updates appear automatically in the app.

Features:
- JavaScript and DOM storage
- Website login/session cookies
- File upload fields
- Android Downloads support
- Back-button web navigation
- External phone/email/WhatsApp links open with Android apps

The APK is built by the GitHub Actions workflow on the `yesstudy-android` branch.
